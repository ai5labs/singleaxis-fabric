=====================================================================
WARNING: Langfuse is configured with an inline `database.url`.

The DSN (which contains the database password) is stored in the Helm
release record, in `helm get values`, and in any rendered-manifest
pipeline (GitOps diffs, CI output). For anything beyond a local dev
cluster, reference an existing Secret instead:

  --set langfuse.database.url="" \
  --set langfuse.database.dsnSecret.name=<secret> \
  --set langfuse.database.dsnSecret.key=url
=====================================================================
{{- end }}
{{- if not .Values.securityContext.readOnlyRootFilesystem }}

NOTE: this deployment runs with a writable root filesystem — the only
subchart in the distribution that does. Reason: the Langfuse v2 image
runs Prisma migrations at boot and writes temporary engine files; we
have not verified a read-only profile against the pinned image, and
we do not ship untested hardening. If you need it: set
`securityContext.readOnlyRootFilesystem: true` plus writable emptyDir
mounts at the paths Prisma writes (discover via `strace` or by booting
with --read-only and reading the EROFS errors), and verify a full
migration cycle in your environment first.
=====================================================================
{{- end }}
